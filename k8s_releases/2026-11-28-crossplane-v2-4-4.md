**Version**: v2.4.4

### Changelog

`v2.4.4` is a patch release scoped to fixing issues reported by users of Crossplane `v2.4` and fixing security related issues in Crossplane's dependencies.

# 🎉 Highlights

* **Namespaced XRs can no longer compose cluster scoped resources:** A function could make a namespaced XR compose a cluster scoped resource by setting `metadata.namespace` on it, because the scope check only ran on composed resources without a namespace. Crossplane now checks the scope of every resource a namespaced XR composes, based on its kind. Backported in #8053, originally fixed in #8050.
