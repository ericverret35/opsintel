### Changelog

## Highlights

Flux v2.10.1 is a patch release that fixes credential caching across the controllers, so changes to the `credential.auth.fluxcd.io/username` and `gcp.auth.fluxcd.io/workload-identity-provider` ServiceAccount annotations take effect on the next reconcile instead of continuing to use the previously cached authenticator until it expires or the controller restarts. It also resolves the default decryption ServiceAccount lazily for Kustomizations that only use Age or PGP keys, restores authentication to registries whose token service runs on a private address and after same-host HTTP to HTTPS redirects by updating ORAS to v2.7.0, and fixes Git checkouts that deleted the target of a relative symlink or got permanently stuck when the push branch removed a file that relative symlinks
