## A simple phone input with country flags, dial codes, and a number field.

**Source**: Dev.to

     

 A lot of phone inputs require installing a large library. 

 But if you only need a country selector and a number field, why add the extra weight? 

  SonoJS Phone Input  keeps it simple: country selection, dial codes, optional country flags, and a phone number field. No phone validation package required. 
 

 
  npx @sonojs/ui@latest add phone-input
  

 



  Live demo:   https://sonojs.com/docs/components/phone-input
