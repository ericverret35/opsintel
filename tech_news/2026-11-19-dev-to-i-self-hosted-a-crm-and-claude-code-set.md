## I self-hosted a CRM and Claude Code set up a sales pipeline in 58 seconds. Here's what MCP got right and wrong

**Source**: Dev.to

 I gave Claude Code one prompt against a CRM running on my own server. 58 seconds later there was a Deals list with five demo deals in EUR, and a board grouped by stage. This post walks through that run: the install, the MCP connection, the prompt, the calls, and what you don't get when you self-host. 

 It is one run with Claude Code on Sonnet, not a benchmark. The deals are demo data. 

 Context: Customermates is an open-source CRM that helps a small team follow up on every client conversation
