## Building an open source subscription backend

**Source**: Dev.to

 My first attempt to add subscriptions to my app failed, so I built SubTru. SubTru is an open source, self-hostable API that processes subscription events from Stripe, the Apple App Store, and Google Play. Your app can then call SubTru's  GET /access  endpoint to fetch any user's subscription status.
