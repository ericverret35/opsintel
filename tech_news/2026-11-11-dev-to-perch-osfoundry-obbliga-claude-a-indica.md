## Perché osFoundry obbliga Claude a indicare la scheda Slides esatta e a usare una chiave per ogni citazione?

**Source**: Dev.to

 Questa è la chiamata di creazione che una connessione Claude riceve per le Notes di  osFoundry , ottenuta con un  tools/list  non autenticato sull'endpoint MCP pubblico il 2026-11-09 e accorciata: 
 

 
   {  "name"  :   "create_note_tab"  , 
  "description"  :   "Create a new Slides or Sheet tab in an approved Note. Use the version from list_note_tabs; returns the exact new tab ID for later edits. An optional outline fills a Slides tab. A repeated idempotency key returns the first tab."  ,
