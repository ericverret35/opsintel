## LLM Security Needs Capability Scoping, Not Better Prompts

**Source**: Dev.to

 
  TL;DR —  Filtering and classifier-based guardrails treat prompt injection as a text-matching problem, but attackers only need one novel phrasing to win. The durable fix borrows from network security's 'assume breach' posture: tag content by provenance, propagate that taint through the pipeline, and scope what tools an agent can invoke based on where its instructions actually came from. Defense in depth here means the model can be compromised and the system still doesn't act.
