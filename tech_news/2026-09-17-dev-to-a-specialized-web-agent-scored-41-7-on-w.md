## A specialized web agent scored 41.7 on WebRetriever while GPT and Claude failed the same form-filling task

**Source**: Dev.to

 General-purpose LLMs are bad at browser automation. I spent the last few months working with various computer-use agents, and the performance gap between specialized models and general ones is way bigger than most people expect. 

 Heres a concrete example. On WebRetriever Protocol I, a benchmark that tests real browser navigation and form-filling, Mano-CUA 1.1 scored 41.7 NavEval. Gemini 2.5 Pro Computer Use got 40.9. Claude 4.5 Computer Use landed at 31.3. The full project is at  github.com/M
