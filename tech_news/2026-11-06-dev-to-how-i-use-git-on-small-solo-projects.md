## How I Use Git on Small Solo Projects

**Source**: Dev.to

 Most of my code lives in small projects with exactly one contributor: me. A screen scheduling script, a folder of Python helpers, a data cleanup tool. For a while I treated Git on those projects as a backup button. I typed a commit once a day with a message like "updates" and moved on. Then I needed to find the exact change that broke something, and a month of "updates" told me nothing. 

 Git is not only for teams. On a solo project it is your memory, your undo button and your safety net. Here
