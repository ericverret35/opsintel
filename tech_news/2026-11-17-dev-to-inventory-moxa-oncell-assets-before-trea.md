## Inventory Moxa OnCell assets before treating CVE-2026-111461 as patched

**Source**: Dev.to

 
  
  
  Inventory Moxa OnCell assets before treating CVE-2026-111461 as patched
 

 A CVE record can create an assumption that a vendor patch exists somewhere and that the main task is deployment. CVE-2026-111461 breaks that assumption. The affected OnCell G3150A-LTE Series is end of life, and Moxa's mitigation is to keep SMS management disabled rather than to install a new firmware release for this line.
