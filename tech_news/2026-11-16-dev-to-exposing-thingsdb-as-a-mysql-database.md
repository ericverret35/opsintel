## Exposing ThingsDB as a MySQL Database

**Source**: Dev.to

 Integrating a high-speed, object-oriented database with traditional reporting tools, BI dashboards, or legacy applications often hits a familiar roadblock: most external tools expect SQL. 

 With the new MySQL Endpoint module ( module-go-mysqlendpoint ), ThingsDB can now speak the MySQL wire protocol directly. This allows you to connect standard MySQL clients, BI tools (like Grafana, Metabase, or Power BI), and existing SQL drivers straight to your ThingsDB collections, no ETL pipelines or data
