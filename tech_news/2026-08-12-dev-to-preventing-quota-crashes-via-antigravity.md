## Preventing Quota Crashes via Antigravity CLI Agent Hooks

**Source**: Dev.to

 
  
  
  Solving the LLM quota monitoring paradox with zero-overhead local Connect RPC agent hooks.
 




 
  
  
  Abstract
 

 Google Antigravity CLI users using Google OAuth face abrupt task failures when API quota hits 0%, while account switching triggers unrecoverable signature errors. Querying quota via LLM tool calls creates a paradox by consuming the very tokens being monitored. We resolve this with  antigravity-cli-check-usage-plugin , a CLI Agent Hook running outside the LLM execution
