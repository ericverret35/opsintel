## AWS App Runner alternatives: ECS Express Mode and where else to run your container

**Source**: Dev.to

 AWS App Runner is closed to new customers, and AWS says it does not plan to add new features. Existing customers can keep using it, including creating new services, and no end-of-life date has been announced. AWS recommends Amazon ECS Express Mode as the replacement. Outside AWS, Render, Railway, Google Cloud Run, Lightsail container services and Ownkube cover the same job of running a container from a repo or an image behind an HTTPS URL.
