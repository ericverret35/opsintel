## Setting Firefox Bookmark Keywords From an Extension, Without an API for It

**Source**: Dev.to

 I use bookmark keywords all day. Type "jira" in the address bar, hit enter, and you're on the board. Firefox gives a keyword the top "Visit" suggestion in the URL bar, so it's faster than any search or history match, and it syncs to every machine you're signed in on. 

 When I wrote  Passport Containers , a Firefox add-on for per-path container rules, I wanted to set the keyword right from the popup. Make a rule for the site, bookmark it, give it a keyword, done. The first two parts were easy.
