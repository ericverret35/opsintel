## Building a Serverless Student Data App on AWS with S3, CloudFront, API Gateway, Lambda and DynamoDB

**Source**: Dev.to

 I recently built a small but complete serverless application on AWS: a web page where you can save a student's record and view everyone who has been saved. There are no servers to manage, no containers, and almost nothing billing when nobody is using it. 

 In this post I'll walk through how I put it together, the code I used, the mistakes I made along the way, and what I would change before calling it production-ready. 

  Who this is for:  anyone with an AWS account who wants a hands-on first
