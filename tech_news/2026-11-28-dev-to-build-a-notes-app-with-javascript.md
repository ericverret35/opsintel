## Build a Notes App with JavaScript

**Source**: Dev.to

 A notes app is the classic beginner project because it covers the full CRUD cycle: create, read, update, and delete. Add localStorage and your notes survive a refresh — suddenly it is not a demo anymore, it is a tool you can actually use. 

 
  
  
  What you are building
 

 A text input to add a note, a list of notes, edit and delete buttons on each note, and a search box to filter them. Everything is saved in localStorage. 

 
  
  
  The data model
 

 Keep one array as the source of truth.
