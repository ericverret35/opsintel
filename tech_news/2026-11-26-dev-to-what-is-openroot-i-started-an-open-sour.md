## What Is OpenRoot? I Started an Open-Source Developer Program for Useful Projects

**Source**: Dev.to

  By Kristofer Jussmann  

 I'm Kristofer Jussmann, and I started  OpenRoot , an open-source developer program and builder community. The idea is simple: build something useful, host it in the open, keep direction of your own work, and have a place that will help people find it. 

 This post is a hub for what OpenRoot is, why I started it, how you can join or contribute, and four projects I have been shipping inside the  OpenRootdev  GitHub organization: Harneloop, ToolIndex, ViperMesh for Blend
