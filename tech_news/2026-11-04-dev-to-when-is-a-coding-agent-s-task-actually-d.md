## When is a coding agent's task actually done?

**Source**: Dev.to

 An agent stops typing and the spinner goes away. Is the task finished? 

 It's tempting to say yes. It isn't: the agent has only run out of things to do and is waiting for my next message. I haven't read the diff, the checks haven't run on the merged result, and nothing is on main.
