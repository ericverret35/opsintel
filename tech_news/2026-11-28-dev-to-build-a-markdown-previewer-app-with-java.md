## Build a Markdown Previewer App with JavaScript

**Source**: Dev.to

 A Markdown previewer shows formatted text as you type — write  # Hello  on the left, see a big heading on the right. It is the tool behind every README editor and blogging platform, and building a simple one teaches you string parsing, live rendering, and layout in one project. 

 
  
  
  What you are building
 

 A split screen: a textarea on the left, a preview pane on the right. As the user types Markdown, the preview updates instantly. Support headings, bold, italic, links, lists, and code
