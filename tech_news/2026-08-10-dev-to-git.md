## Git: ডেভেলপার ও শিক্ষার্থীদের জন্য একটি পূর্ণাঙ্গ গাইড

**Source**: Dev.to

 
  
  
  🚀 Git: ডেভেলপারদের জন্য Version Control-এর সম্পূর্ণ গাইড
 

 
  "Code লিখা যতটা গুরুত্বপূর্ণ, সেই code-এর পরিবর্তনগুলো সঠিকভাবে manage করাও ততটাই গুরুত্বপূর্ণ।"  
 

 আপনি যদি Web Development, Software Development অথবা Programming শেখেন, তাহলে খুব দ্রুতই  Git  নামটির সঙ্গে পরিচিত হবেন। 

 শুরুতে Git-এর commandগুলো একটু কঠিন মনে হতে পারে।  git add ,  git commit ,  git push ,  git pull ,  branch ,  merge —সবকিছু একসাথে দেখলে মাথা ঘুরে যেতে পারে! 😅
