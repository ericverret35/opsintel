## devtemDesign 0.1.0: one config object paints a whole landing page

**Source**: Dev.to

 Every landing page I built started the same way: nav, hero, feature cards, pricing, FAQ, footer, then a day of making it responsive. So I wrote an engine that does that part for me. 

  devtemDesign  takes one config object and renders the whole page. No framework, no build step, no dependencies. Two tags and one function call. 

 This post is both an introduction and a reference for  v0.1.0 .
