## Ashby's public job posting API: what one request returns, and five things to handle

**Source**: Dev.to

 More than two thousand companies hire through Ashby, and every Ashby job board is also a public JSON API. Ashby publishes it so that a company's jobs can be shown anywhere; it needs no key for reading. One request per company returns the whole board. We built a search on it this autumn; this is what the API gives you, measured on 14 November 2026 on two boards, OpenAI (838 open jobs) and Notion (166).
