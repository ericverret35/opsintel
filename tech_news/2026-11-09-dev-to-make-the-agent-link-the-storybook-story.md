## Make the agent link the Storybook story in the PR body

**Source**: Dev.to

 A UI PR that says “added Empty and Error stories” without a link is half-finished handoff. Reviewers open Storybook, guess the title, scroll the sidebar, and hope they found the right export. Agents are especially good at this omission: the stories file lands in the diff, the PR body stays a wall of prose. 

 I’ve started treating a  Storybook permalink in the PR body  as a merge requirement for agent UI work — same tier as “tests green.” One URL. Named story. Reviewers stop foraging.
