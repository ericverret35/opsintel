## Buildroot for Embedded Linux — Part 1: Your First Buildroot Root Filesystem

**Source**: Dev.to

 
 Buildroot builds a cross-compiler, a Linux kernel and a complete root filesystem from source, driven by one Kconfig-style configuration file. Starting from the  qemu_arm_vexpress_defconfig  that ships with Buildroot 2026.05.1, two commands produce a bootable ARM system you can run under QEMU. The images you ship are the ones in  output/images/ ;  output/target/  looks like a root filesystem but must never be copied to a device.
