## Give Claude Code a Memory: claude-mem Remembers Between Sessions

**Source**: Dev.to

 
  
  
  What it is
 

 claude-mem is a free, open-source tool that gives your coding agent a memory across sessions. A coding agent is a program that writes and edits code for you from plain prompts. Each new session starts blank. The agent re-reads the same files, re-asks the same questions, and repeats mistakes you already fixed. claude-mem records what happens in each session, and it hands the key facts to the next session.
