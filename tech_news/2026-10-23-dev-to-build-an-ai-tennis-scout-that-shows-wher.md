## Build an AI tennis scout that shows where every fact came from

**Source**: Dev.to

 A useful tennis scout should be able to answer a follow-up: “Which matches support that statement?” 

 If the answer is another paragraph of confident prose, the scout is difficult to trust. If the answer is four match links, a cutoff timestamp and a calculation you can repeat, you have something you can put in front of a reader. 

 This project combines two Actors and a language model. The match lookup provides the target and its stored pre-match ratings. Player history provides earlier result
