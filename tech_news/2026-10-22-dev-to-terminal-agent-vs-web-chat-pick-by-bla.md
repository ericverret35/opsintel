## Terminal Agent vs. Web Chat: Pick by Blast Radius

**Source**: Dev.to

 Every major AI lab now ships a command-line agent that runs on your machine with access to your files and shell. The deciding factor is which tasks you deliberately keep out of it. The deciding factor is simpler than most teams make it. 

 
  
  
  The Idea: Scope the Damage, Not the Capability
 

 The better question when evaluating a terminal agent is blast radius: if this thing does exactly the wrong thing, what does it touch and how fast can you undo it? A web chat window has a blast radius
