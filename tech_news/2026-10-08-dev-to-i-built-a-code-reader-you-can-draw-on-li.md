## I built a code reader you can draw on like a PDF

**Source**: Dev.to

 Sometimes I don't want to run code. I just want to read it and scribble on it, like a PDF. 

 So we made  AnnotateCode . Paste a GitHub link, then highlight, circle and leave notes right on the code. It saves in your browser, so it's all still there when you come back. 

 free and open source. 

 👉 Try it:  annotatecode.com
