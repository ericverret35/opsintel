## Build an Image Slider App with JavaScript

**Source**: Dev.to

 An image slider — also called a carousel — appears on almost every website, from product pages to photo portfolios. Building one teaches you array indexing, CSS transitions, timers, and touch-friendly controls. It is a small project with a very visible result. 

 
  
  
  What you are building
 

 A row of images where only one is visible at a time, with previous and next buttons, clickable dots for each image, and optional auto-play that pauses when the user hovers over the slider.
