**Source**: Dev.to

 
  
  
  LangChain
 

 
    Programming Framework    
 
 LangChain  is an   open-source orchestration framework   designed to help developers build applications using large language models (LLMs) 
 Its used by developers to connect LLMs to external databases, APIs, and tools so they can become "Agents." 
 Who is the Agent here ? --&gt; No, LangChain itself is not the agent.. 
 LangChain is the Operating System / Framework . 
 The Agent is the running system --&gt; " Agent " is the final, fully
