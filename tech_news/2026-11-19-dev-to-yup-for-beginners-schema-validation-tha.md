## Yup for Beginners: Schema Validation That Reads Like English

**Source**: Dev.to

 Yup is a schema validation library for JavaScript that lets you describe the shape of your data once, then validate it anywhere — in a form, in an API request, or in a test. Instead of writing nested if statements to check that an email looks like an email and a password is long enough, you write a schema that reads almost like English.
