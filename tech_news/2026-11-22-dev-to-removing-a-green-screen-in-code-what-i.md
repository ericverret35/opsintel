## Removing a green screen in code: what I learned open-sourcing a video matting pipeline

**Source**: Dev.to

 This pipeline started as the Standard pipeline behind  Zapmatte , the hosted green screen remover I run: upload a clip on the website, get a transparent video back. The hosted version made the workflow a form instead of a timeline — but every step inside it was still code, and code can be shared. So I took that pipeline, cleaned it up, and open-sourced it. This post is the tutorial I wish I had at the start: what the pipeline does, in what order, and how to run it.
